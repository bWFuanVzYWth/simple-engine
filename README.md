# simple_engine

Rust / Slang 图形库，跨平台模块化引擎

## 功能

- 色彩管理
- 光谱大气与地形遮挡产生的太阳体积光
- LOD 管理器
- Hash DAG
- 稀疏体素网格化
- 最少矩形分解
- Open PBR
- 光源重要性采样
- 朴素路径追踪
- ReSTIR PT Enhanced / ReSTCV
- UI
- Sip Hash
- 柏林噪声
